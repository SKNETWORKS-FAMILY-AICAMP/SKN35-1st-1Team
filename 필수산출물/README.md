# 필수산출물 화면

부트캠프 제출용 3개 화면만 모아 놓은 **독립 실행 앱**이다.

```bash
streamlit run 필수산출물/app.py
```

| 화면 | 파일 | 내용 |
|---|---|---|
| 🗄 DB 설계 | `schema.py` | 테이블 스키마 5종 + ERD 요약 |
| 📁 수집 데이터 | `rawdata.py` | 원본 데이터 형태·출처·CSV 다운로드 |
| ℹ 프로젝트 소개 | `about.py` | 목적·기술스택·산출물·프로젝트 구조 |

`sample_data.py`는 '수집 데이터' 화면에서 쓰는 예시 데이터, `style.css`는 이 화면 전용 스타일이다.

## 이 폴더가 따로 있는 이유

본 앱(`main.py`, 해치타GO)은 팀 통합 앱이고, 이 3개 화면은 **부트캠프 제출용 문서 성격**이라 팀 저장소에는 필요 없을 수 있다.

그래서 의존성을 한 방향으로만 두었다.

- 이 폴더는 `../common`, `../style`, `../config` 를 **참조하지 않는다** (자체 `style.css` 보유)
- 본 앱도 이 폴더를 참조하지 않는다

**팀 저장소에 합칠 때 필요 없으면 이 폴더를 통째로 지우면 된다.** 본 앱은 아무 영향 없이 그대로 동작한다.

같은 내용의 문서 버전은 [`../docs/`](../docs/) 에 있다.
