# 전달 메모 — FAQ 파트 (이세희)

서울시 장애인콜택시 조회 시스템 중 **FAQ 파트** 구현본입니다.
팀 저장소 구조(`main.py` + `views/` + `common/` + `style/`)에 맞춰 정리해 두었습니다.

## 바로 실행

```bash
pip install -r requirements.txt
streamlit run main.py
```

**MySQL 없이도 그대로 돌아갑니다.** `data/processed/`의 정제 CSV로 자동 전환되도록 만들어서
DB 세팅 없이 화면을 바로 확인하실 수 있습니다. MySQL로 보시려면 아래를 추가로 하시면 됩니다.

```bash
copy .env.example .env      # 접속 정보 입력
python db/loader.py         # 스키마 생성 + 적재
```

## 합치실 때 보실 것

제가 만든 건 **FAQ 화면 하나**입니다. 나머지는 자리표시(placeholder) 상태입니다.

| 메뉴 | 상태 |
|---|---|
| ❓ FAQ | ✅ 완료 — `views/faq.py` (FAQ 21건 · 키워드 105건) |
| 📰 관련뉴스 | 화면만 선구현 — `views/news.py` (데이터는 예시) |
| 📊 이용현황 | 미구현 — 자리표시 |
| 📝 예약하기 | 미구현 — 자리표시 |

연결은 두 줄이면 됩니다.

```python
from views.faq import render as render_faq

if menu == "faq":
    render_faq()
```

## 파일명이 겹치는 것 3개

| 파일 | 조율 방법 |
|---|---|
| `main.py` | 팀 라우터를 기준으로 삼고 `RENDERERS`의 `faq` 항목만 옮기시면 됩니다 |
| `style/style.css` | 공통 스타일이라 양쪽 내용을 합쳐야 합니다. 페이지 전용은 `faq.css`로 분리해둬서 충돌하지 않습니다 |
| `db/` | 팀 쪽은 `db.py`, 제 쪽은 `repository.py`라 파일명이 달라 그대로 공존합니다 |

`views/faq.py`·`news.py`는 `reserve.py`·`useStatus.py`와 이름이 겹치지 않습니다.

## 지우셔도 되는 것

`필수산출물/` 폴더는 **부트캠프 제출용 화면**(DB설계 · 수집데이터 · 프로젝트소개)입니다.
팀 통합 앱에 필요 없으면 **폴더째 지우셔도 됩니다.** 본 앱이 이 폴더를 참조하지 않아
지워도 아무 영향 없습니다.

## 구조

```
main.py          라우팅만 담당
views/           화면 — home / faq / news / placeholder
common/          브랜드 상수 · SVG 에셋 · CSS 로더 · 사이드바 · 뉴스 데이터
style/           CSS — style(공통) / home / faq / news
db/              MySQL 스키마 · 적재 · 조회 계층
crawler/         BeautifulSoup · Selenium 수집
preprocess/      전처리 파이프라인
data/            raw(원본 JSON) · processed(정제 CSV)
docs/            산출물 문서 3종
필수산출물/       제출용 화면 (독립 실행 · 삭제 가능)
```

의존 방향이 `main.py → views/ → common/ · db/` 한 방향이라 순환 임포트가 없습니다.

자세한 내용은 [`README.md`](README.md)에 있습니다.
