# 서울시 장애인 콜택시 이용현황 분석 및 자동차 보조기구 지원 조회 시스템

부트캠프 팀 프로젝트 — **데이터 조회 프로그램(Streamlit GUI) 화면 프로토타입**

> ⚠️ 현재는 UI/화면 구성 확인용 단계입니다. 크롤링/DB 연결 없이 **더미(예시) 데이터**로 동작합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

브라우저에서 자동으로 열리며, 기본 주소는 http://localhost:8501 입니다.

## 화면 구성 (사이드바 8개 메뉴)

| 메뉴 | 설명 |
|------|------|
| 🏠 홈 | KPI 카드 + 이용 안내 |
| 📊 이용현황 | 연도·월·자치구 검색 → 표 / 막대·원형·라인 그래프 |
| 🦽 보조기구 조회 | 장애유형·종류·제조사 검색 → 카드형 출력 |
| 🏛 지원정책 조회 | 지역·대상·기관 검색 → 테이블 |
| ❓ FAQ | 카테고리 + 아코디언 |
| 🗄 DB 설계 | 테이블 스키마 문서 (필수 산출물 ①) |
| 📁 수집 데이터 | 원본 데이터 형태 + CSV 다운로드 (필수 산출물 ②) |
| ℹ 프로젝트 소개 | 목적 / 기술스택 / 구조 |

## 역할 분배 포인트

데이터 소스는 `streamlit_app.py` 상단의 아래 4개 함수로 분리되어 있습니다.
각자 맡은 부분을 **함수 반환값(컬럼 구조)에 맞춰** 실제 크롤링/MySQL 결과로 교체하면
화면 코드는 수정하지 않아도 됩니다.

- `make_taxi_usage()` — 콜택시 이용현황
- `make_devices()` — 자동차 보조기구
- `make_policies()` — 지원정책
- `make_faqs()` — FAQ

## 필수 산출물

1. 데이터베이스 설계 문서 → `🗄 DB 설계` 메뉴
2. 수집 데이터 → `📁 수집 데이터` 메뉴
3. 데이터 조회 프로그램 → 본 Streamlit 앱
