# 실행 가이드 및 문제 해결

담당 파트: FAQ · 대상 환경: Windows 11 · Python 3.13 · MySQL 8.4 · Chrome

---

## 1. 사전 준비

### 1.1 의존성 설치

```bash
pip install -r requirements.txt
```

| 패키지 | 용도 |
|---|---|
| `requests`, `beautifulsoup4`, `lxml` | 정적 페이지 수집·파싱 |
| `selenium`, `webdriver-manager` | 동적 페이지 수집 (Chrome 필요) |
| `pandas` | 전처리 |
| `pymysql`, `python-dotenv` | MySQL 연동 |
| `streamlit` | 조회 GUI |

> Selenium 4.6 이상은 **Selenium Manager**가 크롬드라이버를 자동으로 내려받는다.
> 별도 chromedriver 설치가 필요 없다. (Chrome 브라우저는 설치되어 있어야 함)

### 1.2 MySQL 접속 정보

```bash
copy .env.example .env
```

`.env`를 열어 값을 채운다.

```ini
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=여기에_본인_비밀번호
MYSQL_DATABASE=seoul_calltaxi
MYSQL_CHARSET=utf8mb4
```

> `.env`는 `.gitignore`에 등록되어 있어 커밋되지 않는다. 비밀번호를 코드에 직접
> 적지 않는다.

접속 확인:

```bash
python -c "from db.loader import check_connection; print(check_connection()[1])"
```

## 2. 전체 실행 순서

```bash
# ① 수집
python crawler/faq_board_bs4.py         # 게시판 FAQ 8건
python crawler/guide_pages_bs4.py       # 안내페이지 34섹션
python crawler/faq_board_selenium.py    # 동적 아코디언 8건 (교차검증용)

# ② 전처리
python preprocess/build_faq_dataset.py  # → FAQ 21건 / 키워드 105건

# ③ DB 적재
python db/loader.py                     # 스키마 생성 + 적재 + 이력 기록

# ④ 조회 프로그램 실행
streamlit run app/main_app.py
```

각 단계는 독립적으로 재실행 가능하다. `content_hash` UNIQUE 제약 덕분에
③을 여러 번 실행해도 데이터가 중복되지 않는다(UPSERT).

## 4. DB 확인 (DBeaver)

접속 정보: `localhost:3306` / 사용자 `root` / 데이터베이스 `seoul_calltaxi`

```sql
-- 적재 결과 확인
SELECT c.category_name, COUNT(*) AS 건수
FROM faq f JOIN faq_category c ON c.category_id = f.category_id
GROUP BY c.category_id, c.category_name, c.sort_order
ORDER BY c.sort_order;

-- 키워드로 FAQ 검색
SELECT DISTINCT f.faq_id, f.question
FROM faq f
LEFT JOIN faq_keyword k ON k.faq_id = f.faq_id
WHERE f.question LIKE '%요금%' OR k.keyword LIKE '%요금%';

-- 수집 이력
SELECT * FROM crawl_log ORDER BY run_at DESC;
```

우클릭 *Export Diagram*으로 PNG 저장(보고서 첨부용).

## 5. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `Access denied for user 'root'@'localhost'` | `.env`의 비밀번호가 비었거나 틀림 | `.env`의 `MYSQL_PASSWORD` 확인 |
| `Can't connect to MySQL server` | MySQL 서비스 미기동 | `Get-Service *mysql*` 로 상태 확인 후 시작 |
| 화면 하단에 `CSV(대체)`로 표시됨 | MySQL 접속 실패 또는 미적재 | `python db/loader.py` 실행 |
| `FileNotFoundError: faq_clean.csv` | 전처리 미실행 | `python preprocess/build_faq_dataset.py` 먼저 실행 |
| Selenium이 즉시 종료됨 | Chrome 미설치 / 버전 불일치 | Chrome 설치 후 재시도. 실패해도 ①②는 정상 동작 |
| 크롤링 중 `요청 실패` | 사이트 일시 오류 | 자동 3회 재시도. 계속 실패 시 잠시 후 재실행 |
| 한글이 깨져 보임 | CSV 인코딩 | 모든 CSV는 `utf-8-sig`로 저장됨. Excel에서 정상 표시 |

## 6. 발표 시 안전장치

MySQL이 준비되지 않은 PC에서도 화면이 동작하도록 조회 계층이 자동 전환된다.

```
MySQL 접속 시도 → 실패 → data/processed/faq_clean.csv 로 조회
```

현재 어떤 방식으로 조회 중인지는 FAQ 화면 하단
**`ℹ️ 데이터 출처 및 시스템 정보`** 항목에서 확인할 수 있다.
정식 시연에서는 `MySQL 연결됨 · seoul_calltaxi · FAQ 21건` 이 표시되어야 한다.
